🧢 Cap Widget - Iframe Test

This page demonstrates the Cap CAPTCHA widget working in a standalone context. It simulates how the widget would work when embedded in an iframe, such as in a Telegram mini webapp.

📝 Configuration Required

To enable iframe support in your Cap standalone server, set these environment variables:

ALLOW_IFRAME=true FRAME_ANCESTORS=https://web.telegram.org https://telegram.org CORS_ORIGIN=https://web.telegram.org,https://telegram.org

For local testing, you can use '*' for FRAME_ANCESTORS to allow all origins.

Note: This test page uses a custom fetch function to simulate the Cap challenge/redeem flow. In production, make sure your Cap server is properly configured with the correct site key.

🔧 Integration Example

To integrate Cap in your webpage or Telegram mini app:

<script src="https://your-cap-server.com/assets/widget.js"></script> <cap-widget data-cap-api-endpoint="https://your-cap-server.com/YOUR-SITE-KEY/"></cap-widget>
